Входящие сообщения по логистике сохраняются в выбранную Google Таблицу: текст, дата, отправитель и идентификаторы сообщения.

Политика конфиденциальностиУсловия использования

Текущая версия

Текстовые сообщения

Приложение получает сообщения через Telegram-бота и регистрирует их для дальнейшей работы логиста.

Автоматическая загрузка вложений и обработка с помощью ИИ в этот сценарий n8n ещё не включены.

01 / ПОЛУЧЕНИЕ

Сообщение в Telegram

Бот получает текст, время отправки и данные отправителя.

02 / ОТВЕТ

Подтверждение получения

Бот сообщает, что получил сообщение.

03 / ЗАПИСЬ

Строка в Google Таблице

Сценарий добавляет запись в настроенный лист. Результат можно проверить в таблице.

Для чего нужен доступ к Google

Доступ к Google Таблицам нужен для выбора рабочего документа, чтения структуры листа и записи входящих сообщений. Google Drive API используется при выборе документов и получении необходимых сведений о них.

Владелец аккаунта подключает Google через окно разрешений Google. Перечень запрашиваемых прав отображается при подключении. Доступ можно отозвать в настройках своего Google-аккаунта.
